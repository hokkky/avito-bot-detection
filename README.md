# Детекция ботов по журналу событий

Тестовое задание Авито: по журналу действий пользователей (330 тысяч событий) предсказать, какие куки — боты. Метрика — precision при recall 0.7 (P@R70).

## Результат

| Признаки | P@R70 |
|---|---|
| Только объём активности (baseline) | 0.10 |
| Объём + тайминги | 0.29 |
| Все 73 признака | **0.75 ± 0.01** |

Валидация по времени: три даты разреза, по три сида на каждую.

## Подход

- Признаки — агрегаты по куке в пять групп: тайминги между событиями, положение активности в окне, содержание (объявления, категории, поиск), окружение (платформа, курсор, user-agent), популярность объявлений и дубликаты строк.
- Популярность объявления считается строго по дням до окна. Тот же счётчик по всем дням давал около 0.85, но заглядывает в будущее, поэтому не используется.
- Вклад групп оценён абляцией, не только по feature importance.
- Модель — LightGBM, финальное предсказание усредняется по пяти сидам.
